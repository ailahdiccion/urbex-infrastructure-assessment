# URBEX | Urban Infrastructure Assessment

A React-based web application prototype designed to explore urban infrastructure assessment through simulated scoring, area comparisons, and interactive reporting.

Developed collaboratively by Team CRAFx for Codewarts: The Wizarding Hackathon.

## Key Features

- Urban infrastructure assessment interface
- Simulated infrastructure scoring
- Infrastructure indicator visualization
- Area comparison
- Interactive assessment reporting
- Web-based user interface

## Local Setup

### Prerequisites

- Node.js
- npm

### Installation

1. Open the project root directory in a terminal.
2. Install the required project dependencies:

   `npm ci`

3. Start the development server:

   `npm run dev`

4. Open the local URL displayed in the terminal.

## Project Status and Limitations

This application was developed as a hackathon prototype and is not intended for production deployment.

Infrastructure assessment results and scoring are simulated for demonstration purposes. The current implementation does not include a functional AI backend or independently validated infrastructure assessment data.

The portfolio version has not undergone full runtime testing or a comprehensive security audit.
